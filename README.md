# Task Management App

During this lab session, we developed a Task Management App using React Native and Expo.

- **Dashboard:** Displays saved tasks using `ScrollView` and retrieves task data from AsyncStorage.
- **Add Task Screen:** Allows users to enter a task name and description, save tasks locally, and receive a local notification when a task is saved.
- **Profile Screen:** Allows users to enter their student name and ID, select a profile image from the gallery, and save profile details locally.
- **Navigation:** Used Expo Router to navigate between the Dashboard, Profile, and Add Task screens.
- **Local Storage:** Used AsyncStorage to store and retrieve task and profile data.
- **Notifications:** Used Expo Notifications to display local notifications.
- **Image Picker:** Used Expo ImagePicker to select and edit a profile image from the device gallery.

The app was developed using Visual Studio Code, React Native, and Expo.
